# 神田川 防災カルテ

神田川流域の住所を入力すると、想定浸水深・とるべき行動・水につからない最寄りの
指定緊急避難場所を1枚のカルテとして表示するWebアプリです。

作品「神田川は、忘れていない — 水位のいまと、氾濫の記憶」の別館。
本編: https://s-01kxrfpaap3j0hz2hq0x6nb17g.visualizer.reearth.io

## 使い方

`index.html` と `shelters.json` を同じフォルダに置き、ブラウザで `index.html` を開きます。
GitHub Pages などに置く場合も、2ファイルを同じ階層に置くだけで動きます。

※ `index.html` を単体でダブルクリックして開くと、ブラウザの制限で
`shelters.json` を読めず避難場所が表示されないことがあります。その場合は
簡易サーバ経由で開いてください（例: `python3 -m http.server` を実行し
`http://localhost:8000` を開く）。

## 主な機能

**その場所の想定浸水深**　ハザードマップポータルの配信タイルを1画素ずつ読み、国土交通省の6色のどれに当たるかで判定します。透明な画素は「区域の外」、区分の境界にあたる半透明の画素は「判定できない」として、断定しません。

**避難経路の途中の浸水深**　いちばん近い避難場所までを直線で結び、途中20か所の浸水深を調べて、いちばん深いところを示します。行き先が安全でも、そこへ向かう道が3mの水に浸かるなら、水が出てから動くことはできません。ただし直線であり、実際に歩く道とは異なります。

**避難場所を3か所**　最寄りだけでなく近い順に3か所を出します。1か所だけでは、混雑や通行止めがあったときに行き場がなくなるためです。新宿区のように、区内の指定緊急避難場所がすべて洪水非対応で、隣の区まで出る必要がある地域もあります。

**結果の共有と印刷**　調べた地点は URL に残るので、そのリンクを家族に送れば同じカルテが開きます。地図と入力欄を除いてカルテだけを印刷することもできます。停電や通信の途絶に備えた機能です。

## 収録データと出典

| 項目 | 出典 |
|---|---|
| 想定浸水深（タイル） | 国土交通省 ハザードマップポータル 洪水浸水想定区域（想定最大規模） |
| 浸水想定の前提 | 東京都建設局 神田川流域浸水想定区域図（2024年2月15日指定／1時間153mm・24時間690mm） |
| 指定緊急避難場所 301か所 | 国土地理院 指定緊急避難場所データ（2026年7月18日取得） |
| 洪水予報 | 気象庁 防災情報JSON |
| 背景地図・住所検索 | 国土地理院タイル／国土地理院ジオコーダ |

避難場所の緑（洪水に対応・177か所）と赤（洪水に対応しない・124か所）は、
自治体が指定した災害種別「洪水」の区分をそのまま色に置き換えたものです。
独自の判定はしていません。渋谷区・武蔵野市は同データに未登録のため含みません。

## デザインの準拠

見た目は次の公的規定に合わせています。独自の配色を作っていません。

- UI基調色・文字・余白・フォーム: デジタル庁デザインシステム（DADS）デザイントークン
- 浸水深の6色: 国土交通省 洪水浸水想定区域図作成の手引き（旅行者や通勤者が
  どこにいても同じ色で同じリスクを認識できるよう、国が統一している配色）
- 警戒レベルの5色: 内閣府 避難情報に関するガイドライン

## 注意

浸水想定にはシミュレーションの誤差が含まれ、隣り合う土地でも表示が
大きく異なる場合があります。実際に避難するときは、必ずお住まいの自治体が
発表する最新の情報とハザードマップを確認してください。

## リアルタイム情報について（できること・できないこと）

**できること — 洪水予報の自動判定**

気象庁の防災情報XML随時フィード（`https://www.data.jma.go.jp/developer/xml/feed/extra.xml`）
を5分ごとに読み、神田川の指定河川洪水予報が発表されていればページ上部に表示します。
氾濫注意＝警戒レベル2相当、氾濫警戒＝3相当、氾濫危険＝4相当、氾濫発生＝5相当として、
内閣府ガイドラインの配色でレベルを示します。洪水予報が出ていないときは、
流域9区市の大雨・洪水警報／注意報（気象庁 `warning/130000.json`）を補助的に表示します。

洪水予報は**発表されているときだけ**フィードに載ります。平常時に何も出ないのが正常です。

**できないこと — 10分ごとの実測水位**

東京都水防災総合情報システムの水位CSVは、ブラウザから別オリジンで取得することが
できません（CORSが開いていない）。実測水位のリアルタイム表示には、
サーバまたはCloudflare Workers等の中継が必要で、GitHub Pagesのような
静的ホスティングだけでは実現できません。

このアプリで「リアルタイム」と呼べるのは洪水予報と警報・注意報までです。
10分ごとの水位は、本編アーカイブに2026年6月3日の記録として収録しています。

**動作確認（2026年7月20日時点）**

| 取得先 | 別オリジンからの取得 |
|---|---|
| 気象庁 防災情報XMLフィード | 200 OK |
| 気象庁 警報・注意報JSON | 200 OK |
| 東京都 水位CSV | CORSでブロック |
